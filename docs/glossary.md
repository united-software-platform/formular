# Глоссарий понятий проекта

Единственный источник определений понятий проекта: каноническое имя, английское имя
и определение. Общепрограммные понятия и понятия отдельных инструментов в глоссарий
не вносятся — он описывает предметную область этого репозитория.

## Беклог

### Беклог операции (Operation Backlog)

Порождённый файл, несущий порядок задач одной операции и значения, которыми они исполняются.
Носитель порядка работ и следа исполнения: отвечает и на вопрос «что делать по порядку»,
и на вопрос «как прошёл этот прогон».

### Операция (Operation)

Единица работы, порядок которой описывает беклог. Беклог нужен операции, у которой есть
необратимый шаг либо шаг, выполнимый только владельцем; прочим операциям носитель порядка
для одного вызова превращается в обёртку.

### Фронтматтер беклога (Backlog Frontmatter)

Блок значений в начале беклога, из которого исполнитель берёт данные операции. Повторный сбор
значений запрещён: он допускает расхождение между подтверждённым и выполненным. Значения,
добытые исполнением, дописываются сюда же.

### Шаблон операции (Operation Template)

Файл, описывающий состав задач одной операции: подстановки значений, условные блоки и текст
задач. Единственный источник состава задач — порождённый беклог задним числом не правится,
правится шаблон. Версию шаблона называет сам шаблон первой строкой.

## Исполнение

### Исполнитель беклога (Backlog Runner)

Носитель порядка исполнения беклога: один порядок отметок, признаков «выполнено ранее»
и стоп-знаков на все операции. Беклог порождает прогон, исполняет — исполнитель; описанный
в каждом шаблоне, порядок исполнения стал бы несколькими носителями одного правила.

### Признак исполнения (Completion Marker)

Состояние, по которому задача признаётся выполненной ранее. При расхождении с отметкой
в беклоге верно состояние: отметка переживает откат и прерванный сеанс, а состояние нет.

### Стоп-знак (Stop Sign)

Признак задачи, необратимой для внешних ссылок или публичного состояния: такая задача
исполняется только после отдельного подтверждения владельца, запрошенного непосредственно
перед ней. Утверждение беклога таким подтверждением не является.
