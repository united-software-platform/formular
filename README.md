## Что это

Беклог — носитель порядка работ одной операции и следа её исполнения. Он нужен операции,
у которой есть необратимый шаг либо шаг, выполнимый только владельцем: порядок, записанный
в беклоге, не теряется при обрыве, а каждая задача несёт проверку и признак «выполнено ранее»,
по которому исполненное распознаётся заново.

Система делает две вещи: порождает беклог по шаблону операции и несёт порядок, по которому
беклог исполняется. Исполняет его агент — по навыку
[`backlog-run`](./.claude/skills/backlog-run/SKILL.md).

Нормы беклога — в [правилах](./rules/operation-backlog-rules.md) (`BKL-001`..`BKL-009`),
понятия — в [глоссарии](./docs/glossary.md).

## Запуск

Порождение беклога образцовой операции:

```bash
sh tools/backlog/backlog.sh generate --operation sample-operation \
  --value target=проба --flag host-part
```

- `--operation` — имя операции, оно же имя файла шаблона;
- `--subject` — предмет беклога; без него предметом становится штамп прогона `YYYYMMDDHHMMSS`;
- `--value ключ=значение` — значение подстановки шаблона, повторяется по значению; каждому
  значению заводится парная подстановка `ключ_scalar` в виде, пригодном для фронтматтера;
- `--flag имя` и `--no-flag имя` — признак условного блока, взведённый и снятый; признак,
  не названный вовсе, порождение останавливает;
- `--root` и `--templates` — каталог следа и каталог шаблонов; умолчания `backlog` и `templates`.

Коды возврата: `0` — беклог порождён либо уже лежал, `1` — ввод не позволяет его породить,
`2` — ошибка вызова или окружения. Состав вызова целиком — `generate --help`.

Порождённый беклог не перезаписывается: повторный вызов над тем же адресом отвечает путём
лежащего файла и оставляет его неизменным.

## Разработка

Проверки ядра — грамматика шаблона, маркер версии, вид значения фронтматтера, запрет
перезаписи:

```bash
python3 -m unittest discover -s tests
```

Правила репозитория и точка их подключения в контекст агента — [`CLAUDE.md`](./CLAUDE.md).
Работа ведётся изменениями OpenSpec: предмет системы описан спецификацией
[`openspec/specs/backlog/operation-backlog/`](./openspec/specs/backlog/operation-backlog/spec.md).
